# App Store Assets - Version 1.4

These marketing screenshots were composed on macOS (using SF Pro Rounded + Nunito Black) from live captures of the version 1.4 (build 12) debug fixtures with `-releaseMarketingPreview` on real iPhone 6.9-inch and iPad 13-inch simulators via `scripts/capture-appstore-raw.sh` and `scripts/render-appstore-screenshots.py`. The fictional roster is Miles, Ned, MJ, and Peter using the shipped Neon player palette.

## Notes

- Simulator mode remains gated behind `#if DEBUG` (`DealerAvailability.isPreviewEnabled`) and is excluded from App Store screenshots via `-releaseMarketingPreview` so every depicted feature is reachable in Release.
- The setup screen is omitted from public screenshots so no expansion mode label or rules-like line appears on App Store media.
- All headlines, sublines, and marketing copy avoid third-party marks, publisher names, and sequel titles per `docs/APP264401-I-path-forward.md`.
